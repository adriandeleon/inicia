Security

inicia runs installers with administrator rights, so it only runs ones it has checked. This page says what it checks, what it never does, and where it still falls short.

Every download is checked before it runs

  • From the publisher. Each app's address is the publisher's own download (GitHub releases, the publisher's site or CDN, or an official mirror), recorded in the catalog.
  • Over https only. A download that redirects to plain http is refused.
  • SHA-256. An app pinned to a version has the exact fingerprint of its installer in the catalog, matched against what the publisher lists where they list one. A download that doesn't match is deleted and never runs.
  • Publisher signature. Where the catalog names a signer, the installer's Authenticode signature must be valid, trusted by Windows, and made by that publisher (Google LLC, Mozilla Corporation, Microsoft Corporation…). Downloads that always fetch the latest release are checked this way, since their file changes with every release.

The catalog it fetches is signed

Each run, inicia fetches the latest catalog from this site, so a saved exe installs current versions. It's only taken when its Ed25519 signature matches the public key built into the exe (the private key exists only as a secret of the site's publishing job), when it's no older than the exe's own catalog, so an old one can't be replayed to roll versions back, and when this inicia can read it. Anything else, and inicia uses the catalog built into it.

What inicia never does

  • install toolbars, trials or anything you didn't pick: an installer that bundles offers doesn't go in the catalog;
  • run a download it couldn't check;
  • send anything about you or your PC anywhere: it downloads installers, nothing else;
  • restart Windows.

How the catalog is kept honest

Every catalog change is a public pull request on GitHub. CI builds inicia, really installs apps on Windows with it, and a weekly job checks that every installer is still at its address and still the size the catalog says: a changed file would no longer match its SHA-256.

Where it falls short, for now

  • inicia's own exe isn't code-signed yet, so Windows SmartScreen warns the first time it runs.
  • Downloads wait in your temporary folder between the check and the install. Another program running as you could, in principle, swap one there.

Reporting a problem

If you find a security problem in inicia or its catalog, please report it privately through GitHub's security advisories rather than in a public issue.
