How inicia works

One small program installs the Windows apps you pick: silently, each download checked before it runs, with nothing extra.

Getting your installer

Tick apps on the Apps page and select Get your installer. Every download is the same inicia.exe; only its name changes: inicia_7zip_vlc_python.exe. The name is the list of apps, so keep it as it is. A browser's (1) is fine. A whole category or suite goes in the name as one word (inicia_cat-media_suite-vitrina.exe), and Select all gives inicia_all.exe.

Run it. Installers need administrator rights, so Windows asks for them; then inicia's window shows each app's progress and one bar for the whole run. Show details shows everything it does (Copy details copies it), and Cancel stops after the app being installed. When it's done, it says what it installed and what it left alone; if an app failed, Retry failed tries it again and Open the log folder shows its download and installer log. The taskbar button shows the progress too, and flashes when it's done.

A plain inicia.exe, with no apps in its name, opens as a picker: search, tick apps, see their sizes and which are installed already, and choose Install.

Windows SmartScreen may say it "protected your PC" the first time: inicia's exe isn't code-signed yet. Choose More info, then Run anyway.

The page also gives you the same picks as a command (Copy command) or a list file (apps.txt), and the address of the page keeps your picks, so you can bookmark or share it.

Your picks are also kept in your browser (its local storage; nothing is sent to the site), so they're ticked again on your next visit. Forget my picks, under the list's heading, removes them. A link with picks in it takes their place.

What happens when it runs

  1. It makes a plan. inicia reads Windows' list of installed programs (the same one Settings › Apps shows) and decides, per app: install, upgrade, or leave it alone. Apps another app needs come first, such as the Visual C++ runtime for VirtualBox.
  2. It downloads each installer from the publisher's own address, over https only.
  3. It checks the download (see below). If the check fails, the installer never runs.
  4. It runs the installer silently, with the switches that installer takes: no wizard, no offers, no restart.
  5. It confirms the install by finding the app in Windows' list again, then deletes the installer.

At the end it says what it installed, what it left alone and what failed, and why. If anything failed, the downloads and logs stay in a temporary folder it names.

How downloads are checked

Every installer in the catalog has at least one of these, and inicia checks every one it has:

  • SHA-256: the exact fingerprint of the file the catalog was made with. Used for apps the catalog pins to a version. Where the publisher lists its own hashes (GitHub release digests, SHA256SUMS files), the catalog's match them.
  • Publisher signature: the file's Authenticode signature must be valid, trusted by Windows, and made by the publisher the catalog names, such as Google LLC or Mozilla Corporation. Used for "latest" downloads, whose file changes with every release, and as a second check for many pinned ones.

Addresses must be https, and a redirect to plain http is refused.

Updates

Run the same file again any time. Apps older than the catalog's version are upgraded; up-to-date ones are skipped without downloading anything. Apps the catalog installs as "latest" (Chrome, Firefox, Spotify…) update themselves, so inicia leaves an installed copy alone.

From the command line

inicia list                          # the catalog, by category
inicia install 7zip vlc python       # these apps
inicia install cat-developer-tools   # a whole category (inicia list shows each one's name)
inicia install suite-vitrina        # every app of a suite
inicia install all                   # everything in the catalog
inicia install -f apps.txt           # ids from a file; # starts a comment
inicia install 7zip --dry-run        # show the plan, change nothing
inicia install git --force           # reinstall even if it's there
inicia install all --quiet --log C:\logs\inicia.log   # for scripts: no output, exit code 0 when all went well
inicia status                        # catalog apps installed here, and which are out of date

From an administrator terminal it installs right there; otherwise Windows asks for administrator rights and the installs run in a window of their own (with --quiet, a hidden one, and the exit code is passed back).

A downloaded inicia_<apps>.exe takes two switches of its own: --silent installs its apps with no window and no output (for deployment tools), and --cli installs them in the console instead of the window.

Exit codeMeans
0Everything installed or was already up to date.
1At least one app failed; the others were installed.
2Nothing to do with what was asked: no apps named, or not on Windows.
3Administrator rights weren't given; nothing was installed.

Installers of your own

A catalog is a JSON file. Give inicia yours with --catalog (a file, or an https:// address): its apps join the built-in ones, and an app with a built-in id replaces that entry.

{
  "catalog": 1,
  "apps": [
    {
      "id": "my-tool",
      "name": "My Tool",
      "category": "In-house",
      "version": "2.1.0",
      "installers": [
        { "arch": "x64", "type": "inno",
          "url": "https://downloads.example.com/my-tool-2.1.0-x64.exe",
          "sha256": "…", "signer": "Example Corp" }
      ]
    }
  ]
}
inicia hash https://downloads.example.com/my-tool-2.1.0-x64.exe   # SHA-256, signer, an entry to start from
inicia check my-catalog.json                                       # every problem, with where it is
inicia install my-tool --catalog my-catalog.json
FieldWhat it is
idLowercase letters, digits and hyphens. Used on the command line and in exe names. all and names starting with cat- or suite- are taken.
versionWhat the installers install. Leave it out for a "latest" address: an installed copy is then left alone.
licenseAn SPDX id (GPL-3.0, MIT…) for open source, or Proprietary, or Subscription when some use needs a paid plan; shown on the card.
releasedWhen the publisher released that version, YYYY-MM-DD; shown on the card.
detect.displayNameA regular expression for the name in Settings › Apps. By default, the name starts with name.
requiresIds of apps to install first.
noteSomething to know before installing; shown on the card and in the plan.
suiteThe family of apps it belongs to; the card says "Part of the … Suite", and suite-<name> selects them all.
archx64, x86 or arm64. ARM64 PCs fall back to x64, then x86.
typemsi, inno (Inno Setup), nsis (/S), or exe with its own args.
sha256The file's hash. Required unless signer is given.
signerThe signing certificate's name (CN or O).
argsExtra arguments after the type's own silent ones.
sizeThe download's size in bytes; shown on the card.

Apps with something to know

  • Docker Desktop: installing it accepts the Docker Subscription Service Agreement; larger companies need a paid plan. It also needs WSL 2.
  • Slack and Spotify install for the Windows account that runs inicia, not for every account on the PC.
  • Python and the .NET SDK install side by side with other versions, as their own installers do.
  • VirtualBox brings the Visual C++ runtime with it.
  • Java: the catalog has the two latest long-term support JDKs, Eclipse Temurin 21 and 25, on the PATH (the one installed last comes first). For other versions and vendors, switching between JDKs per project, and Maven, Gradle or sbt, use jkit: install it with inicia, then jkit install jdk@21 (or maven, gradle, sbt) in a new terminal. jkit offers JDKs from 20+ vendors.

Troubleshooting

inicia works on Windows 10 and 11, x64 and ARM64 (where an app has no ARM64 installer, Windows runs its x64 one). When an app fails, its row says why, and Retry failed tries the failed apps again.

It saysWhat to do
SHA-256 mismatchThe file at the publisher's address changed since the catalog was made, or it was damaged on the way. Retry; if it fails again, the catalog needs an update: tell us.
signed by …, not …
signature isn't valid		The download isn't signed by the publisher the catalog expects. inicia won't run it. Report it.
HTTP 404The publisher moved the file. The catalog needs an update.
tried 3 timesThe network or the publisher's server failed three times in a row. Check the connection and retry.
exit code 1618Another installation is running (often Windows Update). Wait for it to finish, then retry.
exit code 1603 or 1638The installer hit an error, or another version is installed that it won't replace. The log folder keeps the installer's log; uninstalling the old version first usually helps.
Windows' list of programs doesn't show itThe installer finished but didn't register the app the way the catalog expects. It's usually installed anyway.
Nothing happens after the administrator promptThe prompt was declined, so nothing was installed. Run the file again and choose Yes.
"Windows protected your PC"SmartScreen warns about inicia's exe because it isn't code-signed yet: choose More info, then Run anyway.

What inicia doesn't do

  • Microsoft Store apps, such as WhatsApp and ChatGPT: there's no installer file to download and check.
  • Downloads only a web browser can get, such as Claude Desktop's (behind bot protection) and FileZilla's (links that expire): inicia doesn't get around that.
  • Installers that can't run silently, such as Nmap and Zenmap's free installer: silent install is part of the paid Nmap OEM edition.
  • Uninstalling. Use Settings › Apps.
  • Windows on 32-bit PCs, for most apps: the catalog has 64-bit installers.

Building inicia

inicia is a Java program compiled to a native exe with GraalVM. The source, with build steps, is on GitHub.
