The basics

Is inicia free?

Yes. inicia is free and open source, under the MIT license. The apps it installs keep their own licenses: each card says whether an app is open source, proprietary, or needs a subscription for some uses.

Which versions of Windows does it work on?

Windows 10 and 11, on x64 and ARM64 PCs. Where an app has no ARM64 installer, Windows runs its x64 one.

Where do the apps get installed?

Where their own installers put them, as if you had clicked through each one with the default answers: usually C:\Program Files. A few apps, such as Spotify and Slack, install for your Windows account only.

How do I update my apps?

Run the same file again, even one you downloaded long ago: it fetches the latest catalog from this site (signed, so it can't be tampered with), skips apps that are up to date and upgrades older ones. If an app is open, it asks you to close it first.

Can inicia uninstall apps?

No. Use Settings > Apps in Windows; everything inicia installs shows up there.

Safety and privacy

Is it safe?

Every download comes from the app's publisher over https, and is checked against the publisher's SHA-256 or code signature before it runs; anything that doesn't match is deleted and never run. inicia never installs toolbars, trials or anything else you didn't pick. More about how it checks downloads.

Why does Windows say it "protected your PC"?

That's SmartScreen. It warns about programs it hasn't seen signed by a known publisher, and inicia's own exe isn't code-signed yet. Choose More info, then Run anyway. The apps it installs are checked either way.

Why does it need administrator rights?

Most installers need them to install into Program Files, so inicia asks Windows once, at the start, instead of every installer asking. Installers that refuse administrator rights (Spotify's) are run as you, without them.

Does inicia collect any data?

No. It has no telemetry and sends nothing about you or your PC anywhere. It only downloads installers, from their publishers, who see those downloads as they would from your browser. Your picks on this site stay in your browser.

Apps

Why isn't my favorite app here?

An app goes in when its publisher offers an installer that can be downloaded directly and runs silently, without bundled offers. Some apps can't meet that:

  • Microsoft Store only (WhatsApp);
  • downloads only a web browser can get (FileZilla's expiring links);
  • installers that can't run silently, or only in a paid edition (Nmap and Zenmap, Wireshark's capture driver);
  • installers that bundle other products.

The search on the Apps page tells you when an app is one of these.

Can I suggest an app?

Yes: suggest it on GitHub.

How does inicia keep up with new versions?

Every day, an automatic job checks each app's publisher (and winget's manifests) for a new version, downloads it, checks its fingerprint, installs it on a test PC, and proposes the update. Once it's merged, every copy of inicia picks it up the next time it runs.

What's the Vitrina Suite?

Apps by inicia's author: Editora, Termina, Torrenta, Mirada, Nux, Modula and jkit. Their cards say "Part of the Vitrina Suite", and you can pick them all at once.

How do I get Java, Maven, Gradle or sbt?

The catalog has Java 21 and Java 25 (Eclipse Temurin). For other versions and vendors, and for Maven, Gradle and sbt, install jkit, then run jkit install jdk@21 (or maven, gradle, sbt) in a new terminal.

Work and scripts

Can I use inicia at work, or in scripts?

Yes. It has a command line for administrators and deployment tools: inicia install 7zip vlc --quiet --log install.log, or inicia_7zip_vlc.exe --silent, with exit codes that say how it went. Some apps have their own terms for business use (Docker Desktop needs a paid plan in larger companies). See the docs.

Can I add our own in-house apps?

Yes: write a catalog file for them and pass it with --catalog. How.

Does it work behind a proxy?

Yes. It uses Windows' proxy settings, or the one you name with --proxy host:port or the INICIA_PROXY variable, with a password if the proxy asks for one. More.

How is inicia different from Ninite or winget?

Like Ninite, you pick apps on a web page and get one installer that sets them all up silently. Unlike it, inicia is open source, has a free command line, and takes catalogs of your own apps. winget is Microsoft's package manager, run from a terminal; inicia uses winget's public manifests as one of the places it learns about new versions.
