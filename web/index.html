How it works

  1. Run the file you download. Its name says which apps to install, so keep the name as it is. Windows asks for administrator rights, which installers need.
  2. inicia checks every download against the hash in its catalog or the publisher's code signature, and stops if it doesn't match.
  3. Apps you already have are left alone, and older versions are upgraded. Run the same file again any time to update.

Windows only (x64 and ARM64). From a terminal, inicia install takes the same ids, or a list file: inicia install -f apps.txt.
